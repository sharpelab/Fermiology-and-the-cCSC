# Python dependencies for the CSC fermiology figure notebooks.
# Tested with Python 3.12.3. The raw-sweep loader (`sweep`) is vendored under
# utils/sweep/ and needs NO external lab package.
#
#   python -m venv .venv && source .venv/bin/activate   (or: uv venv)
#   pip install -r requirements.txt                     (or: uv pip install -r requirements.txt)
#
# Versions are pinned deliberately. Two reasons:
#
#   1. Numerics. These notebooks were written against NumPy 1.x; NumPy 2.0
#      removed implicit shape-(1,) -> scalar assignment, which broke three of
#      the SI figure notebooks outright.
#   2. Rendering. matplotlib 3.10.8 reproduces the published figures exactly
#      (pixel-identical). matplotlib 3.11.0 renders the same data differently --
#      measured at ~1.9% of pixels on si-fig16-fft-hightone-filters. If you
#      upgrade matplotlib, expect the regenerated PDFs to differ cosmetically
#      from the ones in the paper.
#
# If you only want to read the code, none of this matters. If you want to
# reproduce the figures, use these versions.
